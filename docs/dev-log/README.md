# Week 1 Dev Log

This week I built the core structure of a card battle game using Java OOP concepts.

I learned how to use abstract classes, inheritance, and polymorphism in a real project. The Card system was designed using an abstract class with multiple subclasses like AttackCard, HealCard, and BuffCard.

The most challenging part was managing game flow between Player and AIPlayer, especially handling mana and card selection logic.

I also learned how to use Git properly with branches and commits, and how to structure a project into src and docs folders.

Overall, I now understand how OOP concepts connect in a real game system, not just theory.
